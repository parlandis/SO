# Sistemas Operativos

Un proyecto educativo sobre conceptos fundamentales de sistemas operativos implementado en C.

## 📋 Descripción

Este repositorio contiene código y ejemplos sobre temas clave en sistemas operativos, incluyendo:

- Procesos y threads
- Sincronización y exclusión mutua
- Gestión de memoria
- Sistemas de archivos
- Scheduling y planificación
- Comunicación entre procesos

## 🛠️ Tecnologías

- **Lenguaje**: C (95.5%)
- **Build System**: Makefile (2.4%)
- **Scripts**: Shell (2.1%)

## 📦 Requisitos

- GCC o Clang
- Make
- Linux/Unix

## 🚀 Compilación

```bash
make
```

## 📚 Estructura del Proyecto

```
.
├── src/          # Código fuente
├── include/      # Headers
├── Makefile      # Configuración de compilación
└── README.md     # Este archivo
```

## 💡 Uso

Para ejecutar los ejemplos:

```bash
make run
```

Para limpiar los archivos compilados:

```bash
make clean
```

## 📝 Notas

Este proyecto es con propósitos educativos para entender los conceptos fundamentales de sistemas operativos.
